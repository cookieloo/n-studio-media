# n-studio-media

Public image host for the SNS posts of yorld's novels. Instagram's publishing API only accepts
images at a public URL, so each episode's card images are uploaded here **just before** they are
posted, by the publish tool in the private studio repository.

- Layout: `<genre-account>/<work>/ep-NNN/card-NN.png` (e.g. `muhyeop/layback/ep-002/card-01.png`).
- Only images that are being published go here. No manuscripts, canon, plans, or credentials.
- Everything here is public once uploaded and is the same content readers see on Instagram.
